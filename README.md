# Customer-Churn-Analysis-and-Prediction

Customer Churn Analysis & Prediction Dashboard using Power BI, SQL, Python, Power Query, DAX, and Machine Learning.

## Project Overview

This project analyzes customer churn behavior and predicts customers who are likely to leave a service. Using Power BI for visualization, SQL for data analysis, and Python Machine Learning for prediction, the solution provides actionable insights to improve customer retention and support data-driven business decisions.

## Dataset Information

| Metric                  | Value |
| ----------------------- | ----- |
| Total Customers         | 6,418 |
| New Joiners             | 411   |
| Total Churned Customers | 1,732 |
| Churn Rate              | 27.0% |

## Key Insights

* Analyzed 6,418 customer records with an overall churn rate of 27.0%.
* Identified 1,732 churned customers and 411 new joiners.
* Competitor-related reasons accounted for the highest number of churn cases.
* Customers on Month-to-Month contracts exhibited the highest churn rate (46.5%).
* Fiber Optic users showed higher churn rates than other internet service types.
* Customers aged above 50 years recorded the highest churn rate among age groups.
* Built a Random Forest Machine Learning model to identify customers at risk of churning.

## Business Problem

Customer churn directly impacts revenue and business growth. This project aims to:

* Identify key drivers of customer churn.
* Analyze customer behavior and service usage.
* Monitor churn KPIs through interactive dashboards.
* Predict future churners using Machine Learning.
* Support customer retention strategies with data-driven insights.
